    How we measure

    Protocol, definitions and known biases: docs/evaluation.md.

    1. Blind writers

      Separate agents write the cases from the label rules, never the code.

    2. Sealed sets

      Hashed and committed before scoring, never opened while tuning.

    3. One scoring

      Frozen code, scored once, published unchanged.

    4. A floor beside each number

      A keyword baseline shows what guessing scores.

    5. Bad numbers stay

      Spent sets are published too.

    Reproduce it

    Deterministic: the same commit gives the same verdicts.

    git clone https://github.com/glowstonesq1/claimtrace
cd claimtrace
python3 scripts/build_site_data.py --check    # rebuilds this page's data
cat evals/datasets/amendments-v2/*.jsonl | sha256sum
git checkout 063f8e0808f5e5882b442db7da5c3c79a9d5ac32
python3 -m venv .venv && . .venv/bin/activate && pip install -e .
claimtrace eval run --suite amendments-v2 --model rules
claimtrace eval run --suite amendments-v2 --model keyword
claimtrace eval report --format markdown

    For core or holdout, use that run’s commit.
