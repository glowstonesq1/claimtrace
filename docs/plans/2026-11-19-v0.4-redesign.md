## Direction (lead's call, recorded)
Name: **Dusk ledger**. One page system across site, figures, README images and the film.

- **Type (the main complaint):** drop Bodoni Moda and Geist. Display Instrument Sans 500 (Ribbon), body Figtree 400/500 at 18px, line-height 1.6 (Ribbon). JetBrains Mono only for clause numbers, ids and figures in tables, never for reading text. Verbatim quotes are set in the body face. Self-host woff2 from `@fontsource/*` with OFL files (CSP stays `'self'`).
- **Colour:** cool near-white paper, blue-grey ink and hairline rules for reading pages (Cobalt). The hero and the film are a dusk band: CSS-drawn evening sky over slate, with the product in smoked glass with a lit top edge (Dusk). Signals: periwinkle/cobalt = supported / current; apricot = replaced or needs review; one muted red = contradiction. Status is never colour alone (label + icon).
- **Hero:** Dusk layout. Left: plain headline, one sentence, primary "Try it on the sample contract", secondary "Use it with Claude". Right: a live glass panel "Sample contract, checked" built from real engine output: rows per commitment, clause 2.1 shows "March 31, 2026" struck, "May 15, 2026" from Amendment No. 1 §1.1, with the quote. This replaces the screenshot.
- **Hero ground:** a faint glyph field made of the sample contract's own text (Cobalt idea, meaningful), fading under the sky. No stock photos.
- **Interactive evidence map** (Bloom tracks + Cobalt connectors): one lane per sample document (MSA, Amendment No. 1, Audit report, Delivery record); clauses are clips on the lanes; connectors show replaces / supports / contradicts. Hover, focus or click a clip: a side panel shows the verbatim quote, section number and what links to it. Keyboard operable, works without motion, data generated at build time from engine output on the samples (extend `scripts/build_site_data.py`, keep `--check` in CI).
- **Information architecture (fix "confusing"):** the home page answers four questions in order: what it does (hero panel), how it decides (evidence map), how to use it (three paths as tabs: in the browser / with Claude / self-host), how good it is (compact numbers with intervals, link to /evidence). Then the film, then footer. Nav: Try it · How it works · Evidence · Get it · Docs, one primary button.
- **Figures:** every picture is a designed frame: real UI captured at 2x, set in the glass panel on the dusk band or on paper with a hairline frame. Same frames feed the README.
- **README:** opens with the hero image, one-line pitch, three ways to use it, the honest numbers table, then the details. No badge wall.
- **Film:** givemotion, 1920x1080, one continuous camera world (no cuts), same tokens and fonts as the site, story: a contract arrives, clause 2.1 lights, Amendment No. 1 replaces it, the audit report is checked, a verified answer with quotes, end card. Alignment verified with `givemotion check`, `review`, `inspect`.
