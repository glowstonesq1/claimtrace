# ClaimTrace v0.3.0

Use ClaimTrace without installing it: in your browser, in claude.ai, or in Claude Code. The engine is the same
rules engine as before; its accuracy did not change in this release. **Not legal advice.**

This is also the first versioned release of the v0.2 engine work (amendment patterns, hidden-text detection,
business days, ICS export, optional OCR, DOCX tables, hash-chained review trail), which was merged without a
version bump. See CHANGELOG.md.

## What's new
- **Try it in your browser** (`/try/`). The engine runs in the tab under Pyodide. Your files are read there and
  never uploaded. The page may only connect to its own site, which it does to download the engine (about 18 MB,
  self-hosted, every file sha256-pinned). Rules only: no language model, no OCR.
- **Claude.ai skill.** Download `claimtrace-skill.zip` from this release, upload it as a skill in claude.ai with
  code execution on, attach documents and ask. **Documents you attach go to Anthropic** under your Claude plan's
  terms; Claude says so on first use.
- **Claude Code plugin.** `/plugin marketplace add glowstonesq1/claimtrace`, then
  `/plugin install claimtrace@claimtrace`. Commands: `/claimtrace:claimtrace-check <folder>` and
  `/claimtrace:claimtrace-ask "<question>" <folder>`. The engine runs on your computer; what it prints, and any
  file Claude opens, enters the conversation. If ClaimTrace is not installed, Claude asks once before installing
  v0.3.0 from GitHub into a private folder, and installs nothing if you say no. `claimtrace-plugin.zip` (with the
  engine included) is attached for use with `claude --plugin-dir` after unzipping.
- **Evidence explorer** (`/evidence/`): every published metric with 95% intervals and the weak ones included,
  the v0.1 to v0.2 history, and the core and amendments-v2 cases with why each passed or failed. The sealed
  holdout is shown as aggregates only.
- **A site built around jobs**: home, Get it (five paths, each saying where your documents go), docs, and shared
  navigation on every page.

## Accuracy, unchanged from v0.2 (rules engine, no language model)
- **Amendments are the weak spot.** On amendment wording the engine had not seen before (the sealed
  amendments-v2 set, n=105), verdict accuracy is **0.60**, 95% bootstrap interval 0.505 to 0.695 (shown rounded
  as 0.51 to 0.70 in the docs and skill, and 0.51 to 0.69 on the evidence page). Four in ten amendment verdicts
  on unseen wording are wrong, mostly "needs review" where a change was real. Check amendment results yourself;
  the skill, the plugin and the try page all say this.
- Hallucination rate 0.00 and false-clear rate 0.03 on the sealed holdout; false-clear 0.00 on amendments-v2.
- Full numbers: docs/evaluation.md and `/evidence/`.

## Not verified yet
- **Nothing here was tested on real claude.ai.** The skill zip is built and run end to end in a fresh virtual
  environment with only pydantic and lxml, sockets and subprocesses blocked. It assumes claude.ai's sandbox has
  Python 3.11+, pydantic 2 and lxml preinstalled, and puts attachments under `/mnt/user-data/uploads/`. If those
  assumptions fail, the runner stops with a plain message. The claude.ai menu names in our docs are described
  generically for the same reason.
- **The Claude Code marketplace install was not run against the published repository.** Its ask-first install
  needs the `v0.3.0` tag to exist on GitHub. `claude plugin validate` runs in the tests only where the `claude`
  CLI is present.
- The try page was tested in Chromium (Playwright) only, not in Firefox or Safari, and not on a real phone.
- The release workflow (`.github/workflows/release.yml`) has not run yet; this tag is its first run.

## Install
- Browser: open `/try/` on the project site.
- claude.ai: `claimtrace-skill.zip` from this release (docs/claude.md).
- Claude Code: see above.
- Local: `make dev && make serve`, or `docker compose up --build`.

## Known limitations
Amendment accuracy as above; rules engine only in the browser and the Claude paths; no OCR in the browser or
claude.ai; the browser and Claude paths keep no library between sessions and have no review trail.
