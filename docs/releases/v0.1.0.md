# ClaimTrace v0.1.0

First public release: a local-first workspace that maps commitments in contracts and related documents,
answers questions only with verified quotes, and checks documents against each other. **Not legal advice.**

## Highlights
- Works offline with no model; the optional local or hosted model never gets the last word (every quote is
  verified by code).
- Amendments are tracked, not overwritten: answers show current wording and what it replaced.
- Evidence checks separate "matching text found" from "sufficient", which is the reviewer's decision.
- Deleting a document erases all derived data (tested), leaving only a content-free record.

## Measured (sealed holdout, rules engine)
Hallucination 0.00 · false-clear 0.03 · contradiction P/R 0.82/0.64 · QA status 0.88 · party attribution 0.97.
**Weak spot:** amendment verdicts 0.61 and effects 0.50. Review amendment results yourself.
Full numbers and caveats: docs/evaluation.md.

## Upgrade / install
`make dev && make serve`, or `docker compose up --build`. The database schema is versioned (migration 001).

## Known limitations
No OCR; tables flattened; small place gazetteer; business days not converted to dates; heuristic
injection detection; single user. See README → Limitations.
