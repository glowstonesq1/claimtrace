# Vendor Security Audit Report

Prepared for Halden Freight Co. Audit period: April 1, 2026 to June 30, 2026. This is a fictional document created for ClaimTrace examples.

## 1. Scope

1.1 This report assesses the security controls that Corvane Software Ltd. (the "Vendor") operates for the Phase 1 System.

## 2. Findings

2.1 Encryption at rest: Customer data is encrypted at rest using AES-256. Control implemented and operating effectively.

2.2 Data location: All Customer data is hosted in the vendor's Dublin, Ireland data centre.

2.3 Incident notification: The Vendor's incident response procedure requires customer notification within 72 hours of confirming a breach.

2.4 Administrative access: Multi-factor authentication is enforced for administrative access to production systems. However, two shared break-glass accounts were found without multi-factor authentication.

2.5 Availability: Measured availability for May 2026 was 99.1%.

## 3. Conclusion

3.1 The auditor did not test penetration testing activities and expresses no opinion on them.
